The structure below represents the intended pattern.

The `registry_uri` field at the top level, if present, SHALL be a persistent URI pointing to an external system where the full consent declaration resides (see xref:consent_external_systems[xrefstyle=full]).

Individual category entries MAY include a `registry_ref` field providing a category-specific reference within the external system identified by `registry_uri`.
