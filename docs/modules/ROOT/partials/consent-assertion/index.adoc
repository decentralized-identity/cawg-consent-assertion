== The consent assertion

A consent assertion SHALL have the label `cawg.consent` and SHALL be carried in the assertion store of a C2PA Manifest as a created assertion.
It is not a gathered assertion.
A consent assertion SHOULD be listed among the referenced assertions of a https://cawg.io/identity/[CAWG identity assertion], so that a named actor attests that the consent references exist and are correctly bound.
The order in which these assertions are constructed is given in xref:consent_binding[xrefstyle=full].

Within a single manifest there SHALL be at most one `cawg.consent` assertion, written at the defined label.
All consent references contributed by the claim signer SHALL be carried within that single assertion, in the `consent_references` array defined in xref:consent_reference_fields[xrefstyle=full], so that they appear at one defined location within the manifest.
Where an asset's provenance includes more than one manifest, and possibly more than one claim signer, a consumer assembles the complete consent picture by reading the `cawg.consent` assertion present in each manifest in the C2PA manifest store.
